ActivityGrid maps ordered values onto a grid of cells, each shaded by intensity. It's the
contribution-graph shape: cadence, streaks, and seasonality, readable at a glance.

## When to use it

- **Good for** — daily activity, streaks and cadence, seasonality at a glance.
- **Avoid for** — exact values, or precise comparison between two individual cells. Color
  intensity is deliberately approximate; pair it with a number when precision matters.

## Sizing

ActivityGrid sizes from `cell` — the edge length of one square in viewBox units. Bump it to
scale the whole grid, or drive the width from CSS to fill a container; the viewBox keeps the
grid's aspect ratio.

## Variants

`layout="strip"` collapses to a single row for inline use.

<LiveDemo label="strip" code={`<ActivityGrid data={data} layout="strip" />`}>

`shape` swaps the cell mark — same data, same levels, different voice: `"round"` for
friendlier product surfaces, `"dot"` adds breathing room in dense strips.

<LiveDemo label="round" code={`<ActivityGrid data={data} shape="round" />`}>
  <ActivityGrid
    data={[0, 1, 2, 1, 3, 4, 2, 0, 1, 3, 2, 4, 3, 1, 0, 2, 4, 3, 2, 1]}
    shape="round"
    cell={12}

  />
</LiveDemo>

<LiveDemo label="dot" code={`<ActivityGrid data={data} layout="strip" shape="dot" />`}>
  <ActivityGrid
    data={[0, 1, 2, 1, 3, 4, 2, 0, 1, 3, 2, 4]}
    layout="strip"

`start` aligns the grid to the real calendar: the first column pads down to the weekday
of the given day (UTC), so rows read as weekdays — Monday first by default
(`weekStart={0}` for Sunday).

<LiveDemo
  label="calendar-aligned"
  code={`// data[0] is Thursday 1970-01-01 → three leading empty slots
<ActivityGrid data={data} start="1970-01-01" />`}
>

    start="1970-01-01"
    cell={12}
    title="Week-aligned"
  />
</LiveDemo>

## Accessibility

Intensity is a color channel, so ActivityGrid always pairs it with a numeric summary of
its total and peak — the information survives forced-colors and color-blind viewing. The
interactive entry adds 2-D arrow-key navigation, announcing each cell's value as you move.
