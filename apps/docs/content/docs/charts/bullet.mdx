Bullet compares one measured value to a target, against a backdrop of qualitative bands
(poor / okay / good). It answers "are we there yet?" in a single row — ideal for progress,
SLAs, budgets, and quotas.

## When to use it

- **Good for** — progress to a goal, a value against a target, KPIs with thresholds.
- **Avoid for** — trends over time (use [Sparkline](/docs/charts/sparkline)) or
  distributions.

## Sizing

`width` and `height` are viewBox units that also set the rendered pixel box — a bullet
reads best wide and short. Omit them and drive the width from CSS to fill a table cell or
card column; the viewBox keeps the aspect ratio.

## Accessibility

Bullet announces its value, its target, and where it lands among the bands — no color is
required to tell whether the target was met, because the measure's length and the target
tick encode it by position. The interactive entry reads the value and target on hover and
focus.
