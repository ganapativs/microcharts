## Static and interactive

Each chart ships two entries. The **static** one is hook-free and server-component
safe — zero client JavaScript, the default. The **interactive** one adds hover,
keyboard navigation, and live announcements. Import whichever the context needs.

```tsx
import { Sparkline } from "@microcharts/react/sparkline"; //             static, RSC-safe
import { Sparkline } from "@microcharts/react/sparkline/interactive"; // hover + keyboard
```
