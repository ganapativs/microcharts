## Static and interactive

Each chart ships two entries — a hook-free **static** default (server-component safe,
zero client JavaScript) and an **interactive** twin from a `/interactive` subpath. Every
chart page lists both import paths; the [Quickstart](/docs/quickstart#add-interactivity)
covers when to reach for which.
