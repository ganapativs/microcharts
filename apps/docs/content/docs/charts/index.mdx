the same prop names mean the same thing everywhere. Pick by the shape of your data

## Two entries per chart

Each chart ships a **static** entry (hook-free, server-component safe, zero client
JavaScript) and an **interactive** entry (`/interactive`) that adds hover, keyboard
navigation, and live announcements. Import whichever the context needs.

```tsx
import { Sparkline } from "@microcharts/react/sparkline"; // static, RSC-safe
import { Sparkline } from "@microcharts/react/sparkline/interactive"; // hover + keyboard
```

Not seeing the chart you need? The catalog grows toward 100 planned types — browse the
[gallery](/gallery) for what's shipped and what's next.
