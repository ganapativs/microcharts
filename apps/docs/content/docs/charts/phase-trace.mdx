PhaseTrace answers "how do two coupled signals move *together*?". Plotting one against the other as a
single trajectory turns lag into loops and regimes into clusters — structure that two separate
sparklines hide. Path order carries time, and the current state is a directed endpoint with an
arrowhead, so "now, and how it got here" reads at a glance.

## When to use it

- **Good for** — coupled-signal phase portraits (CPU × latency, inflation × unemployment).
- **Avoid for** — reading exact values (DualSparkline) or a single series (Sparkline).

## Why this default

A muted trail with an accent tail because "now, and how it got here" is the question — the eye lands
on the recent motion first, then reads the history. Axis and scale choices are stated, never silently
transformed: the axes are named, the domains are linear, and the framing is disclosed. The tail,
endpoint, and arrowhead trio may be restyled but never all removed, because the recoverable time
direction is what separates a phase trace from a scatter.

## Accessibility

The accessible name states the current point and heading — **"Latency vs CPU: now 62, 130; heading
up-right."** The interactive entry steps through the trajectory in time order with ←/→, announcing
each point's index and its value on both named axes.
