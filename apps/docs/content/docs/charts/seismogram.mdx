Seismogram answers "when did things happen, and how hard?". Ticks rise from a baseline:
presence reads as density texture, height as intensity. Long series collapse via
max-per-bucket only — the spike is the chart's whole job, so it always survives, and the
summary is always computed from the raw values, never the buckets.

## When to use it

- **Good for** — error bursts per service, alert density, activity texture in rows.
- **Avoid for** — level tracking (Sparkline) or labeled events (EventTimeline).

## Why this default

Ticks-from-baseline over bars: density reads as texture rather than inviting bar-to-bar
magnitude comparison the strip is too small to support. Barcode mode is documented as
presence-only — a uniform tick is not intensity. A quiet strip renders its baseline at
rest, never a blank hole.

## Accessibility

The accessible name counts the events — **"4 events, peak 8."**, or **"No events."** for
a quiet strip. The interactive entry steps slots with position readouts ("Point 2 of 5:
3."), announces quiet slots as "no data", and Home/End jump to the first/last event.
