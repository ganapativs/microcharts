---

FillWord answers "how far along is this named task?" by making the label _be_ the bar. A muted word
is overlaid with an accent copy of itself, clipped to the value fraction of the word's own inked
extent — so 50% visually bisects the word. The fill is a percentage of the glyphs you see, never of
a hidden wider track. It trades some precision for a read that needs no separate label.

## When to use it

- **Good for** — a labelled progress read in a sentence or cell, a sync/upload status where the label names the task, or a quota/TTL where the word is the metric.
- **Avoid for** — precise percentages (Progress), trends (Sparkline), or many parallel bars (MiniBar).

At 0% the word is entirely the muted track; at 100% it is entirely accent ink — both ends are
honest limits of the same clip, not a special case.

## Why this default

Fill (not drain) is the default because progress is the ninety-percent case — a word filling as a
step completes. `mode="drain"` empties the ink from the left as the value rises, the remaining-time
story that fill cannot tell (TTLs, expiring sessions). Because glyph ink is uneven, fine reads are
±5% — the fill edge lands between letters, not on an exact tick. When you need the number, add
`label="value"` for the percent alongside, or reach for `Progress` when precision is the point.

## Accessibility

The accessible name names the task and its state — **"uploading: 62% complete."** — or, in drain
mode, **"session: 25% remaining."** An empty word reads "No data." The interactive entry glides the
ink edge with a reduced-motion-gated clip-path transition and announces changes through a polite
live region, throttled to at most once a second so a streaming value never spams.
