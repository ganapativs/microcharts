DotPlot answers "how do a few named values compare on one scale?" with the minimum ink
per comparison. Dots over bars when the scale doesn't start at zero — position lies less
than truncated bar length.

## When to use it

- **Good for** — KPI leaderboards, named comparisons in cards, rows where a truncated
  bar would lie.
- **Avoid for** — more than 7 rows or time series (Sparkline).

## Why this default

Without `stem` the domain fits the data (a position read); with `stem` the domain is
forced through zero (a magnitude read) — the prop flips the honesty regime, and the docs
say so. Coincident dots on adjacent rows de-overlap by half a unit; labels truncate by
character count and drop entirely when rows get too dense — all pure arithmetic, nothing
measured.

## Accessibility

The accessible name carries count and extremes — **"3 categories. Highest Ada 96, lowest
Kim 41."** The interactive entry roves rows and announces each with its rank
(**"Ada: 96 — 1st of 3."**).
