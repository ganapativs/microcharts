title: IconArray
description: A countable-rate grid for React — one stated probability made countable, with the denominator always visible.
---

IconArray answers "how likely is this, really?". A stated rate becomes countable: filled
units in a fixed N-unit grid, with the denominator visible. Two moves kill denominator
neglect — the ratio label and the fixed grid. Fill order is contiguous reading-order
(scattered is harder to count), and there are **no partial-unit fills ever**: a sub-unit
rate is flagged, never faked.

## When to use it

- **Good for** — risk in a sentence, uptake / adoption rates, lay-audience probabilities.
- **Avoid for** — a trend (Sparkline) or a full distribution (QuantileDots).
