SparkBar renders discrete values as compact bars from a zero baseline. In `winloss`
mode it collapses each value to a single up/down mark — a streak you can read at a
glance.

## When to use it

- **Good for** — discrete magnitudes, win–loss streaks, period-over-period counts.
- **Avoid for** — a continuous trend shape (use [Sparkline](/docs/charts/sparkline)) or
  hundreds of points, where bars become noise.

## Accessibility

Announced from the data — the example above reads:

> Deploys per day. Trending up 125%. Range 2 to 9. Last value 9.

Sign is doubled by position (above or below the baseline), never by color alone, so the
chart survives forced-colors and color-blind viewing.
