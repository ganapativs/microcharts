Delta is a text-first metric: a signed number with a direction glyph. It reads inline,
next to a KPI, or inside a table cell. Direction is always doubled — a triangle _and_ a
color — so it never relies on color alone.

## When to use it

- **Good for** — a KPI's change, period-over-period percent, inline metric movement.
- **Avoid for** — showing a series or comparing magnitudes across items.

## Sizing

Delta is text, not a fixed box — it takes the `font-size` of whatever wraps it and its
glyph scales in `em`. Size it by the surrounding type: inline it inherits the sentence,
beside a KPI figure lift the font-size.

## Variants

`from` derives a percent change; `positive="down"` flips only the color for metrics where
down is good (latency, churn, cost).

## Accessibility

Delta renders accessible inline text — the glyph is decorative and the value carries the
meaning. Color is a redundant channel on top of the direction glyph and the sign, so the
change survives forced-colors and color-blind viewing. The interactive entry re-announces
the figure through a polite live region when the value changes.
