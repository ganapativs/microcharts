---
title: PercentileLadder
description: A tail-percentile strip for React — p50/p90/p99 as graduated ticks on a zero-anchored track, because the median never tells the latency story alone.
---

PercentileLadder answers "what does the tail look like — not just the median?". Ticks at
the chosen percentiles sit on a zero-anchored track; graduated height and accent make the
**tail** read strongest. Tick distances carry the story, so the origin is never cropped —
and a log transform (for long latency tails) is never silent: an in-chart `log` tag
renders when it applies.

<LiveDemo

<PercentileLadder data={latencies} title="Request latency" />`}
>
  <PercentileLadder

    title="Request latency"
    width={240} height={18}
  />
</LiveDemo>

## When to use it

- **Good for** — latency SLOs in a sentence, the tail per endpoint in tables, payment-size spread.
- **Avoid for** — the odds of an outcome (QuantileDots) or the full distribution shape (MicroBox).
