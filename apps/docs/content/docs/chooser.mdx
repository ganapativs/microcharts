title: Which microchart?
description: A quick decision guide — pick the right microchart by the question you need answered and the shape of your data.
---

Start from the decision, not the chart. Match the question you need someone to answer in a
glance to the shape of your data.

| Your question               | Data shape                   | Use                                         |
| --------------------------- | ---------------------------- | ------------------------------------------- |
| Which way is it trending?   | ordered `number[]`           | [Sparkline](/docs/charts/sparkline)         |
| How big was each period?    | discrete `number[]`          | [SparkBar](/docs/charts/sparkbar)           |
| Win or loss, over a streak? | signs `(+/‑)[]`              | [SparkBar `winloss`](/docs/charts/sparkbar) |
| How much did it change?     | one number (+ prior)         | [Delta](/docs/charts/delta)                 |
| Are we hitting the target?  | value + target               | [Bullet](/docs/charts/bullet)               |
| When was activity high?     | ordered `number[]` on a grid | [ActivityGrid](/docs/charts/activity-grid)  |

## Rules of thumb

- If **shape over time** matters, use a Sparkline. If **individual amounts** matter, use a
  SparkBar.
- If you're about to reach for a progress bar with a goal on it, that's a Bullet.
- If you're tempted by a pie or a gauge — don't. Radial encodings read far slower at this
  size. A Bullet or a Delta answers the same question faster, and microcharts ships those
  instead.
