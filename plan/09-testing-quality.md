## 2. Test matrix

- **React 18 + 19** (real matrix that matters). Node 20/22/24. ubuntu-latest only (SVG lib has no OS runtime surface; visual tests demand single-OS determinism).
- StrictMode on in all component tests.
- Data edge cases as a shared fixture set applied to **every** chart: `[]`, `[x]`, all-equal, with nulls, all-null, negative-only, huge/tiny magnitudes, NaN/Infinity (reject or clamp — documented behavior), 10k points (graceful, though out of scope). This kills the Grafana bug class pre-launch.

## 3. Quality gates (branch protection on main)

1. typecheck (TS 6 strict; adopt **tsgo** — `@typescript/native-preview`, Rust/Go-native TS 7 — the moment it's stable, watch item) · 2. lint **oxlint** (Rust, oxc family — verified 1.72, 2026-06; same toolchain as rolldown/tsdown/Vite 8) · 3. format **oxfmt** (oxc; pre-1.0 but weekly releases — prettier is the fallback if it misbehaves) · 4. unit + property tests · 5. axe pass · 6. size-limit · 7. publint/attw (on release PRs) · 8. visual diff approved (Argos) · 9. zero-dependency check · 10. **knip** (unused deps/exports/files — verified 6.24, 2026-07; keeps the zero-dep guarantee and tiny public surface honest as code grows). Git hooks via **lefthook** (Go, verified active) — no husky.

## 4. Docs-as-tests

- Every doc example is a real compiled fixture (typecheck + render in CI) — docs can't rot.
- Live-prop editors are native React components in Fumadocs rendering the same fixture files — no island bridge (Sandpack dropped — verified stale; see `10-roadmap.md` §3.1).

## 5. Definition of Done — per chart component

- [ ] Static + interactive entries, shared grammar props implemented
- [ ] Edge-case fixture suite green
- [ ] Property tests for its math
- [ ] axe clean; summary generation correct for its data shape; SR script updated
- [ ] Visual baselines (light/dark/tufte presets × default/dense data) approved
- [ ] Size budget entry added and green
- [ ] Doc page: hero, 4 contexts (sentence/cell/card/tab), prop table, a11y note, Tufte note
- [ ] Bench scenario updated
