# microcharts — Planning Documents

> Planning set v1 · 2026-07-06 · Research-backed (live npm/Bundlephobia/GitHub data + primary-source docs, verified July 2026)

**Thesis:** Word-sized charts for React. Zero dependencies, ~1–2 kB per chart, accessible by default, Tufte-grounded, handcrafted-feeling — optimized for hundreds of instances per page. The category leader (react-sparklines, 213k downloads/week) has been dead since 2017; nothing modern replaces it.

## Headline decisions

- **React library first** (vanilla/ASCII/native ports = documented path via React-free `core/`, built only on success).
- **SVG-first, zero runtime dependencies, ESM-only**, per-component subpath exports, React 18+19 peers. No React Compiler in v1; static components are hook-free and the React 18 compiler runtime would violate the dependency policy.
- **RSC-native static charts (zero client JS) — no chart library does this.** Interactivity is a separate opt-in entry.
- **AMENDED 2026-07-08 ([21](21-full-catalog-buildout.md)): the full 100-type catalog ships in `@microcharts/react` (single package — `@microcharts/expressive` cancelled) BEFORE launch**, in five gated batches. The proving five stay the proving five; launch scope is now the whole catalog. Catalog expanded 96 → 100 the same day with four research-verified additions (MicroScatter #35, LikertStrip #36, IconArray Q21, ConfusionGrid F21 — plan/12 audit).
- **v1 = Sparkline (+band), SparkBar (+win-loss), Delta, Bullet, ActivityGrid → full catalog = 100 distinct chart types** (was 96: 34 core + 20 decision micrographs + 22 expressive + 20 frontier — see [05](05-chart-catalog.md), [16](16-decision-micrographs.md), [15](15-expressive-charts.md), [17](17-frontier-charts.md), and the **[visual gallery](chart-gallery.html)**). Decision micrographs are the research-grounded differentiator: uncertainty, comparison, trust, seasonality, and priority charts that answer named real-world questions. Frontier forms absorb useful professional displays from traces, observability, model evaluation, medicine, and instruments. Architecture scales via the shared grammar; specialized data shapes are admitted only when the structure is the story. Pie/gauge not shipped (glanceability research: radial reads up to 6× slower); strictly-better replacements in-catalog.
- **Design principles applied silently** — Tufte/Few ground every default internally; external docs and marketing never lecture about theory. The craft shows, it doesn't preach.
- **Auto-generated natural-language summaries as default aria-labels — verified industry first.**
- **Budgets (v2, 2026-07-08 — plan/21 §1):** ≤ 3 kB gzip/static subpath (≤ 2 kB target), interactive ≤ +1 kB, shared kernel ≤ 5 kB, styles.css ≤ 12 kB, ≤ 6 SVG nodes/chart typical, 0 deps — all CI gates. The old "≤ 10 kB whole library" is retired (barrel tracked + published honestly, not gated).
- **Stack (verification-hardened, Rust/Go-native end to end):** tsdown/rolldown (build) · oxlint (lint) · oxfmt (format, prettier fallback) · lefthook (hooks) · TS 6 strict with tsgo native preview as watch item · Vitest 4 (Vite 8 = rolldown+oxc underneath) + RTL + @fast-check/vitest + @vitest/browser (Playwright provider — real SVG layout for interactive entries) · Playwright-in-Docker + Argos · knip (unused-dep/export gate) · Fumadocs (React/Next-native docs) · Storybook 10 (workshop) · changesets · npm trusted publishing · Renovate · MIT. All picks registry-verified active (rechecked 2026-07-06). No React Compiler in v1 (its runtime package would break the zero-dep guarantee under React 18).
- **Launch:** Show HN with one falsifiable number + live demo (uPlot playbook), a11y engineering story, shadcn-style copy-paste CLI in v1.x, llms.txt at launch.
- **Universal rendering (v1.x, doc 13):** zero-dep pixel-exact exports (SVG with computed-style + font embedding, PNG at print DPI, clipboard), React-free string renderer → email/badges/OG/print, Unicode renderer, context presets (`newspaper`/`magazine`/`poster`/`eink`/`print`).
- **AI-native (v1.x, doc 14):** one JSON chart spec (props-mirroring, JSON-Schema-published) consumed by React, URLs, and ` ```microchart ` fenced markdown blocks; partial-JSON streaming renderer that grows charts token-by-token in AI chats.
